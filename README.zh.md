## 安装

从列表中选择需要的Skill，按照其说明安装。将**完整Skill目录**及随附文件复制或链接到Agent的技能发现目录。

每个Skill的README提供依赖、用法和限制，`SKILL.md`提供Agent读取的执行指令。
