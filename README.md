# kuroneko-cmd-skills

[中文](README.zh.md)

A collection of small, portable skills for AI coding agents. Created and maintained by [KURONEKO-CMD](https://github.com/KURONEKO-CMD).

## Available skills

| Skill | Purpose |
| --- | --- |
| [kuroneko-paper-reader](skills/kuroneko-paper-reader/README.md) | Read one research paper progressively with an interactive HTML reader and source evidence. |

## Installation

Choose a skill from the list and follow its installation instructions. Copy or link the **complete skill directory**, including its supporting files, into your agent's skill discovery directory.

Each skill's README describes its requirements, usage and limitations. Its `SKILL.md` contains the instructions read by the agent.
