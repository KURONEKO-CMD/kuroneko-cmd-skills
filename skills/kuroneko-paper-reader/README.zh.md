# kuroneko-paper-reader

[English](README.md) · [全部Skill](../../README.zh.md) · [Agent执行指令](SKILL.md)

帮助你理解陌生领域的论文：把晦涩的概念、研究方法和证据关系，变成符合你知识背景的分层讲解与交互式图解。你可以先看清论文在解决什么问题，再逐步弄懂它是怎么做的、结论依据是什么，并针对不懂的地方继续追问。

## 使用前提

本Skill承接原文读取之后的理解与讲解：建立索引、分层解释、结合原图并生成交互式HTML。它不内置文档解析器。

你使用的Harness需要预先具备相应的阅读Skill或等效工具：

| 论文形式 | 所需能力 |
| --- | --- |
| PDF | PDF阅读Skill或工具，能提取正文并查看原图；扫描件还需要OCR |
| Word（如.docx） | Word／文档阅读Skill或工具，能读取正文、表格和图片 |
| 网页或链接 | 浏览器或网页读取能力，且能访问论文内容 |
| 其他文件 | 对应格式的阅读能力，也可以直接提供已提取的正文与图表 |

Agent会先使用对应能力读取原文，再由本Skill组织阅读。无需在每次提示词里重复指定读取工具。缺少对应能力时，会说明缺少什么，并请你提供可读取的格式或内容。安装本Skill不会同时安装这些读取能力。

## 安装

下载或克隆仓库后，复制**完整skill目录**，保留references、assets和scripts。不需要npm、marketplace、API密钥或全局配置。打包工具需要Python 3.10以上，仅负责复制原始文件和打包阅读内容，不负责解析原文。

在本仓库根目录运行，将`/path/to/project`替换为目标项目：

```sh
# Codex
mkdir -p /path/to/project/.agents/skills
cp -R skills/kuroneko-paper-reader /path/to/project/.agents/skills/

# Claude Code
mkdir -p /path/to/project/.claude/skills
cp -R skills/kuroneko-paper-reader /path/to/project/.claude/skills/
```

个人安装可将完整目录复制到Codex的`~/.agents/skills/`或Claude Code的`~/.claude/skills/`，也可创建指向完整目录的软链接。更新时替换已安装的skill目录，已有阅读包保留自己的模板，不会自动迁移。

## 开始阅读

在Codex中选择`$kuroneko-paper-reader`，在Claude Code中使用`/kuroneko-paper-reader`，然后附上论文文件、链接或正文，只需说：

> 帮我阅读这篇论文。

默认按完全不懂这个方向来解释，使用你提问的语言，自动采用默认阅读包位置。这些都不需要额外写进提示词。

有具体要求时，可以这样说：

| 场景 | 示例 |
| --- | --- |
| 中度：有一些理解 | 帮我阅读这篇论文。我对这个方向有一些了解，但有些地方不懂。 |
| 深度：专业人员 | 帮我阅读这篇论文。我是这个领域的专业人员。 |
| 使用ImageGen | 帮我阅读这篇论文，并调用ImageGen，基于论文原图制作帮助理解的示意图。 |

ImageGen是可选要求，也可与任一背景组合。只有Harness具备生图能力(比如你订阅了OpenAI的GPT，然后使用Codex的情况下）、且论文原图可用时才调用；默认使用交互式HTML。

首版包含整篇索引、建议阅读路线、必要术语，以及一个结合图解完整讲解的单元。其余部分明确标记为待展开。轻度、中度、深度分别对应零基础、相关领域背景和专业背景，不限制继续深入的程度。

在浏览器打开`reader.html`，可以直接切换已经生成的解释。需要补充时，点击章节中的提示词按钮，可以追加具体问题，然后把提示词粘贴到Agent对话中。Agent更新同一个阅读包，保留已有档位和原始证据。

新对话使用全局的“在新对话中继续”，并提供阅读包位置。换设备或平台时，携带**完整阅读文件夹**，包括原文、素材、内容、模板和状态文件。仅凭skill名称或一份HTML无法恢复不可访问的原始资料。

## 输出与语言

每篇论文独立保存，默认位于工作目录的`paper-readings/`下。阅读包包含原文副本、提取图表、解释片段、`project.json`、界面与模板，以及生成的`reader.html`。HTML内嵌解释和展示图片，可离线阅读，打开原始文件和继续编辑需要完整阅读包。

页面与导出的提示词跟随用户要求的语言。预置英文、简体中文、日文界面，其他语言由Agent补充完整翻译。尚未生成的档位明确显示待生成，原始技术名称和原图像素保持不变。

ImageGen仅在用户明确要求、Harness具备能力时调用，并以论文原图为参考。常规阅读不需要生图服务。来源缺失和图文冲突会保留显示。
